# 产品原型 v1.0 · 使用说明

医院运营数据治理与决策支持平台的**高保真可交互原型**，基于《功能详细设计 v1.0》构建。

## 打开方式
- 直接双击 `index.html`（单文件，纯内联 CSS/JS，**无需联网、无需安装任何依赖**）
- 或在 GitHub 仓库开启 GitHub Pages（Settings → Pages → Source: main / root 或 /docs），在线访问

## 演示要点
| 操作 | 效果 |
|---|---|
| 左侧导航 | 18 个模块按四期+平台分组，点击切换界面 |
| 右上角主题按钮 | ☀浅色 / ◐深色 / ◑护眼，三套皮肤即时切换，偏好本地持久化 |
| 右上角星标 | 打开品牌定制：改系统名 + 选主色，全站实时生效（对比度校验） |
| M6 检查视角模拟 | 点风险点展开**证据链**（规则→口径→数据元→源字段）；含 EMR 全文不可得的**能力降级说明** |
| M8 国考沙盘 | 三个 Tab：指标看板/口径追溯/推演沙盘（拖动滑块看估算，标注"估算"） |
| M12 院长驾驶舱 | 默认首页，三维度总览 + 今日三件事，可点链接跳转对应模块 |
| M18 换肤设置 | 主题切换与品牌定制的完整演示 |

## 数据说明
所有数据为**演示用模拟数据**，非真实患者信息（均已脱敏）。原型用于产品评审与演示，不构成对功能上线状态的承诺——二期/三期模块已标注落地等级（L2/L3）与依赖条件。
